# 🚍 Ruta-Go (Transporte Nátaga - La Plata) | v1.5.0 Ecosystem 🚀

**Ruta-Go** es una plataforma integral de vanguardia diseñada para profesionalizar y optimizar el transporte intermunicipal en la región del Huila (Colombia). Esta versión **v1.5.0 Ecosystem** consolida la unión entre el mundo móvil (Android) y la gestión empresarial (Web Portal), operando bajo una infraestructura blindada y escalable de **Chop Code Solutions**. ✨

---

## 🏆 Hitos de la Suite Integral
*   🌐 **Portal Web Multi-inquilino**: Dashboard de mando para Administradores y Dueños de Flota con aislamiento de datos (RBAC).
*   🎨 **Experiencia Inmersiva Total**: Soporte nativo Android 15 (Edge-to-Edge) mediante el motor `WindowUtils`.
*   🚀 **Landing Page Corporativa**: Escaparate público con propuesta de valor segmentada y enlaces de descarga.
*   🛡️ **Arquitectura de Interfaz Blindada**: Rediseño Material 3 para garantizar integridad visual en cualquier dispositivo.
*   ⌨️ **Gestión de Teclado Inteligente**: Flujo de chat fluido con adaptación dinámica a la apertura del teclado (IME).
*   🔔 **Comunicación C2C**: Motor de notificaciones en tiempo real basado en **FCM v1 y OAuth2**.
*   ⚖️ **Legalmente Transparente**: Módulos de Términos y Privacidad integrados en cumplimiento con la Ley 1581 (Habeas Data).

---

## 🏗️ Stack Tecnológico e Ingeniería

### **Ecosistema Móvil (Android)**
*   **Lenguajes**: Java 17 (Nativo) + XML (Material Design 3).
*   **Patrón**: MVVM desacoplado mediante capas de especialización (Managers y Engines).
*   **Reactividad**: Observación de estado mediante `LiveData`.

### **Ecosistema Web (React Business)**
*   **Core**: React 18 + Vite (SPA Architecture).
*   **Estilos**: Tailwind CSS + Glassmorphism.
*   **Sincronización**: Custom Hooks para monitoreo de flota en tiempo real.

### **Infraestructura Backend (Firebase Cloud)**
*   **Database**: Realtime Database (RTDB) para latencia de milisegundos.
*   **Serverless**: Cloud Functions para orquestación logística (Rotación Nocturna).
*   **Hosting**: Firebase Hosting para la disponibilidad global del portal de socios.
*   **Security**: Reglas ABAC de alta granularidad para proteger la privacidad comercial.
