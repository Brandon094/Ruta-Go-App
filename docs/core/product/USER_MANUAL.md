# 📖 Manual de Usuario - Ruta-Go v1.5.0 Ecosystem

Bienvenido al Centro de Ayuda de **Ruta-Go**. Este ecosistema está diseñado para ser intuitivo, pero aquí tienes una guía detallada según tu rol.

---

## 🚶 1. Guía para Pasajeros
*   **Consulta de Horarios**: Desde el Dashboard, alterna entre rutas usando las pestañas superiores.
*   **Identificación de Viajes**: El sistema marca el viaje más próximo a salir con un borde naranja y el badge **"Siguiente"**.
*   **Reserva Web**:
    1. Haz clic en **"Reservar"**.
    2. Selecciona un asiento libre en el mapa (blanco).
    3. Confirma tu selección. Tu nombre aparecerá en la lista del conductor.
*   **iPhone PWA**: Usa Safari, toca el botón de compartir y elige "Añadir a pantalla de inicio" para una experiencia nativa.

---

## 👨‍✈️ 2. Guía para Conductores
*   **Control de Planilla**: En "Mi Itinerario" verás tus turnos del día.
*   **Venta Física**: Si un pasajero aborda en la calle, usa el botón naranja **(+)** para bloquear el asiento en tiempo real.
*   **Confirmación de Abordaje**: Toca el botón verde en la lista de reservas pendientes para confirmar que el pasajero ya está en el bus. Esto actualiza tus ingresos.

---

## 💼 3. Guía para Socios y Dueños
*   **Monitor de Flota**: El Dashboard principal muestra el estado de tus vehículos y el recaudo bruto del día.
*   **Vinculación de Operadores**: En la sección "Conductores", busca a tu personal por Email para asignarlos a tus buses.
*   **Planilla Global**: Consulta todos los despachos para coordinar la logística con el holding.

---

## 🛡️ 4. Seguridad y Privacidad
*   **Habeas Data**: Tus datos están protegidos. Puedes solicitar la eliminación de tu cuenta desde el perfil.
*   **Periodo de Gracia**: Tras solicitar el borrado, tienes 30 días antes de que los datos desaparezcan definitivamente.
